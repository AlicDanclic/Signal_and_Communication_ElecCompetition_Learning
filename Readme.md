### 已有模块

#### 基于TPS7A4701RGWR的低噪声射频LDO

> 包含5V默认输出,3V3默认输出,1V8默认输出,拨码开关可调输出

整个系统通过MP2236进行初步降压,由于MP2236最大输出为6A,考虑1.5倍余量来说,负载端的最大输出应该使用4A左右,正好可以搭配4个TPS7A4701.
